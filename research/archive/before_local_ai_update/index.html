MEASURED LOCAL PILOT · NO LLM CALLS

LBADS 논문 보완 실험 보고서

실행 시각(UTC): 2026-11-15T12:59:00.395659+00:00

원본 초안의 예정 성능을 실측 결과와 분리하고, 방어 패치 효과와 행동 규칙의 반례를 검증했다.

초안에서 우선 수정할 사항

  1. 예상 결과와 실측 결과 혼용: 초록·결론의 DR 94.2%, FPR 3.8%, 11.3%p 향상, ATD 2.3회를 실측 성과로 쓸 근거가 없다. 초안 6절도 예정치라고 명시한다.
  2. IP ≠ 행위자: 공유 NAT와 IP 회전을 별도 시험해야 한다. 세션 기반도 공격자가 세션을 새로 만들면 끊기므로 만능 해법이 아니다.
  3. 기법 다양성 ≠ 악의적 적응: 이전의 의심 차단 증거, 이후의 의심 기법 변경, 시간 순서를 함께 검사한다. 이번 반례는 개선 필요성을 보여주며 특징 추출기의 실제 성능은 검증하지 않는다.
  4. Risk의 단위 미정: 비율 E, 횟수 S, 요청률 R, 이진 A를 같은 가중합에 넣는 정규화와 창 크기가 없다. 모두 0~1이면 최대 1이어서 θ=70과 비교할 수 없다. Risk=100·Σwᵢzᵢ, zᵢ∈[0,1]로 범위를 정의하고 별도 검증 세트에서 임계값을 정해야 한다.
  5. LLM 지연과 confidence: 자기 보고 confidence 80은 보정된 공격 확률이 아니다. 이번에는 Qwen을 실행하지 않았으므로 1~3초 지연 주장도 검증하지 않는다. 정규화·권한 검사·패치를 요청 경로에 두고 LLM은 비동기 분석 경로로 분리하는 설계를 제안한다.
  6. 데이터셋의 평가 단위: 공개 IDS 데이터의 레이블만으로 차단 피드백에 따른 HTTP 기법 변경의 인과 순서를 입증할 수 없다. 원시 요청·응답·세션·공격자 정책 로그가 있는 폐루프 데이터가 별도로 필요하다.

6.2 행동 규칙 반례 재생

적응형 3종과 정상 반례 4종을 평가했다. 현재 요청의 결과를 사전에 쓰지 않고 이전 요청의 차단 결과만 참조한다. ATD는 최초 기법 변경 요청을 1로 세며 미탐은 별도 표시한다. 초안형 규칙은 최종 LLM 판단이 아니라 분석 후보를 만드는 규칙이다.

해석 한계: HTTP는 고정 사례 16개를 8개 방어 구성에서 10회 반복했다. 1,280개의 독립 공격이 아니다. XSS는 미인코딩 태그 반사 지표이며 브라우저 실행 성공률이 아니다. 행동 재생은 7개 고정 특징 시나리오에 시작 시간만 바꾼 30개 seed를 적용한 것이다. 의심 여부와 기법 특징을 이상적으로 공급하므로 완벽한 결과도 현실 탐지 정확도의 증거가 아니다. 이력 없는 의심 특징 비교군도 경보 발생 지표에서 동일한 결과를 내므로, 이 데이터만으로 행동 이력의 추가 탐지 효과를 입증할 수 없다. 해당 비교군은 기법 변경 전에도 경보가 나므로 악성 요청 판별과 적응행위 판별을 분리해야 한다. Qwen, Snort, RF, Docker, NSL-KDD, CSE-CIC-IDS2018은 이번에 실행하지 않았다.

후속 본 실험 계획

현재는 논문 주장의 전제와 방어 패치를 확인한 예비 실험이다. 다음 단계는 아래와 같다.

  1. 고정 재생 공격과 차단 응답에 따라 다음 행동을 바꾸는 정책 공격자를 동일 예산으로 비교한다. 정책은 결정 규칙부터 시작하고, LLM 공격자 여부를 별도 조건으로 둔다. AI가 공격을 생성했다고 가정하지 않는다.
  2. 무상태 정규화 룰, 시간 이력 룰, 증거 기반 이력, 동기 LLM, 비동기 LLM을 같은 요청 로그와 동일 예산으로 비교한다. 현재 미구현 조건을 결과 표에 실측으로 넣지 않는다.
  3. 공격 템플릿·행위자·캠페인 단위로 개발/검증/최종 평가를 분리한다. 별도 작성자가 만든 정상 트래픽과 보류 공격 템플릿을 포함해 데이터 누출을 줄인다.
  4. 정확한 탐지 레이블과 공격 성공 여부를 분리하여 DR/FPR/F1, 미탐 포함 ATD, 시간 지연, 정상 요청 p50/p95/p99, LLM 호출률·타임아웃·큐 대기·토큰 비용·정상 기능 손상을 함께 평가한다. 캠페인 단위 신뢰구간을 사용한다.
  5. 기법 특징 오염, 세션 회전, 동일 IP 다중 사용자, 24시간 경계, 모델 출력 오류, 로그 안의 프롬프트 인젝션을 평가한다. LLM 출력은 검증된 대응 식별자만 허용한다.

원문과 참고문헌 점검

다운로드 폴더의 원본은 수정하지 않았다. 아래 네 참고문헌의 제목·저자와 초록을 원 출처에서 확인했으나, 초안의 모든 주장과 수치를 검증한 것은 아니다.

  • ZERO-APT: Windows Server 2022 post-exploitation 실험이다. 웹 방어 실험의 직접 비교 수치로 합치면 안 된다.
  • Hybrid LLM-Enhanced IDS: 초록의 6.3% 정확도 개선·9.0% false positive 감소를 확인했으며, 본 환경에서 재현하지 않았다.
  • SHIELD: 호스트 로그 평가이다. LBADS 웹 환경과 평가 단위가 다르다.
  • AMDS: 두 가지 adaptive white-box 변형에 국한된 결과라는 원문의 제한을 함께 적어야 한다.
  • NSL-KDD 공식 안내와 CSE-CIC-IDS2018 공식 안내: 이번에 다운로드·실행하지 않았다. CIC-IDS2018은 네트워크 캡처·시스템 로그·흐름 특징을 제공하므로 실제로 사용할 아티팩트와 파서를 구체적으로 지정해야 한다.

초안 [1], [6], [8]은 이번 작업에서 원문 검증하지 않았다. 특히 [6] DOI는 10.1016/j.eswa.2025로만 기재되어 식별 정보 보완이 필요하다.
