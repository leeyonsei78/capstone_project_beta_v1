# 사후 탐색: 요청 기법 추출과 시간 규칙의 분리

주 실험의 Qwen 전체 이력 판별이 양성 12개 중 2개만 탐지한 것을 확인한 뒤 추가한 분석이다. 주 실험의 프롬프트/결과를 바꾸지 않으며 새로운 미관측 평가 결과로 주장하지 않는다.

가설: 직접 boolean 결론을 내리는 과제에서의 실패가 요청 기법 분류와 사건 순서 결합을 분리하면 줄어드는가? Qwen이 관찰 요청 하나를 none/sql/html/document로 분류하고, 코드가 실제 HTTP 거부 이후 다른 기법이 나타나는지를 판단한다. 전체 이력을 더 잘 이해했다는 증거로 간주하지 않는다. 프롬프트도 변경되므로 표현과 과제 분해의 영향을 분리할 수 없다.

이미 동결된 24개 에피소드의 동일 관찰을 사용한다. 정답/ID는 모델에 제공하지 않는다. 중복 없는 관찰마다 한 번 호출하고 동일 관찰에 예측을 재사용한다. 이것은 비용을 줄이는 명시적 캐시이며 24개 독립 추론으로 세지 않는다. 원시 전체 이력 판별과 호출량/시간을 그대로 비교해 운영 비용 우월성을 주장하지 않는다. 이번 입력/프롬프트 설계 후 결과를 보고 재조정하지 않는다.

시작 전에 별도 manifest에 입력/프롬프트/순서/코드/상위 실험 해시를 저장한다. 모델/seed/출력 예산은 주 실험과 같으며 이미 로드된 모델을 사용한다. 실패 추출이 있는 에피소드는 실패로 기록하며 정상/음성으로 대체하지 않는다. 규칙은 SQL 거부, HTML 삽입, 타인 문서 시도의 순서 관계에만 적용한다. 서버의 안전한 기본 구현은 변하지 않는다.

결과는 주 실험과 분리한 '사후 탐색' 표에 보고한다. 기법 추출 오류와 시간 결합 오류를 점검하고, 독립 작성된 새 시나리오에서 확인해야 할 후속 가설을 제시한다. 강화 규칙과 같은 결과여도 AI 필요성을 주장하지 않는다.
