# LBADS 초안 발전을 위한 로컬 예비 실험

> 이 문서는 2026-11-15의 LLM 없는 기존 실험 계획이다. 2026-11-16 후속 실제 Qwen/고정 SQL 재생은 [SQL_REPLAY_PROTOCOL.md](SQL_REPLAY_PROTOCOL.md)와 [PAPER_LOCAL_STUDY.md](PAPER_LOCAL_STUDY.md)를 참고한다.

이 문서는 실행 전에 작성한 범위와 평가 규칙이다. 원 초안의 예정 결과를 확인된 성능으로 취급하지 않는다. Qwen과 실시간 Codex API를 호출하지 않는다.

## A. 실제 HTTP 방어 구성요소 제거 실험

자체 Papertrail 서버를 별도 프로세스의 loopback 임시 포트에 실행한다. 현재 사용자가 사용하는 8766 서버와 상태를 공유하지 않는다. SQL 매개변수 바인딩, HTML 출력 인코딩, 문서 소유권 검사 세 요소의 2³=8개 조합을 평가한다. 코드와 입력은 같은 저장소에서 작성했으므로 독립적인 블라인드 평가가 아니다.

- 고정 테스트 입력 16개: 공격 8개, 정상/음성 대조 입력 8개.
- 구성마다 10회 반복, 총 1,280개 실제 HTTP 요청. seed 20261115로 구성과 사례 순서를 섞는다.
- SQL/IDOR 공격 결과: 가상 관리자 인증/다른 소유자 문서 접근 성공.
- XSS 결과: 실행 가능한 태그 문자열의 미인코딩 반사 여부. 브라우저 실행 성공률과 구분한다.
- 정상 대조: 틀린 비밀번호의 인증 거부, 일반 검색어의 텍스트 보존, 자기 문서 접근 허용, 없는 문서 거부.
- SQL 오류 메시지 노출이나 정상 비밀번호 인증까지 검증하는 전체 기능 검사는 아니다.
- p50/p95는 순차적인 새 loopback HTTP 연결을 포함한다. 인터넷 지연, 부하 처리량, GPU 추론 지연이 아니다.
- 반복 요청을 새로운 독립 공격 사례로 세지 않는다. 반복은 재현성/시간 측정을 위한 것이다. 단순 반복에 대한 통계적 유의성이나 모집단 신뢰구간은 산출하지 않는다.

## B. 4.3절 행동 규칙 반례 재생

원 논문의 '두 기법 이상 또는 차단 후 세 번 재시도' 조건을 상태 기계로 구현한다. 이는 Qwen의 최종 판단을 포함하지 않은 **후보 분석 트리거**이다. 이 결과를 LBADS의 DR/FPR로 표기하지 않는다.

조건은 (1) 초안형 IP 기반, (2) 의심 차단 증거 이후 의심 기법 변경을 요구하는 IP 기반, (3) 같은 인과 조건에 신뢰 가능한 세션 키를 쓰는 방식이다.

설계 점검 중, 이상적 의심 특징 자체의 영향과 이력의 영향을 혼동할 우려를 확인해 (4) 현재 의심 특징만 사용하는 이력 없는 비교군을 추가했다. 기법 변경 전 경보 수도 따로 기록한다. 이 대조군 추가는 최초 실행 이후 이루어졌으며 후속 재실행 결과가 최종 산출물이다. 사후 추가를 사전 등록으로 표기하지 않는다.

7개 고정 시나리오: 동일 IP 적응형, IP 변경, 10시간 간격, 정상 인코딩 다양성, 정상 권한 거부 재시도, 공유 IP/NAT, 24시간 밖의 기록 만료. 시나리오마다 30개 seed로 가상 시작 시간을 바꾸며, 의미적으로는 7개 사례를 반복한 것이다.

현재 의심 여부와 기법은 생성기가 공급하는 이상화된 특징이다. 실제 HTTP에서 특징을 추출하는 분류기의 정확도, 정상 사용자를 공격자로 오인하는 영향, 공격자가 세션을 회전하는 영향은 이 실험으로 입증하지 않는다. 세션 키는 서버가 신뢰할 수 있다는 가정이며 클라이언트가 임의로 정하는 ID를 신뢰해서는 안 된다.

공유 IP 시나리오에서는 다른 행위자의 이벤트로 상태를 형성하지만 평가 대상 정상 행위자의 경보만 센다. 탐지 지연은 최초 기법 변경 요청을 1로 세는 시도 수이다. 미탐은 평균 지연에서 제외하되 별도 개수로 반드시 기록한다. 24시간은 가상 타임스탬프로 검사하며 24시간 실제 운영 실험이 아니다.

## 입증 범위

방어 패치 효과, 상태 기계의 반례, 응답 시간만 확인한다. LLM 기여, 자동 공격 생성의 효과, 공개 데이터셋 성능, Snort/RF 대비 우월성, 운영 강건성은 검증하지 않는다. 공격 스크립트는 로컬 소유 서버만 접근한다.
