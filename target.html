비밀번호가 틀렸는데도 관리자 로그인이 가능할까요?

정상 값: admin

공격 값: admin' --

admin 뒤에 작은따옴표 하나, 공백, 하이픈 두 개를 입력하세요. 실습 비밀번호는 항상 틀린 값으로 고정됩니다.

정상 값은 로그인 실패, 공격 값은 취약 상태에서 관리자 인증 성공이 예상됩니다. 방어 적용 후에는 공격 값도 실패해야 합니다.

02 / REFLECTED XSS

검색 결과에 코드가 실행될까요?

검색어를 글자로 표시하는지, HTML 코드로 실행하는지 비교합니다.

정상 값: 안녕하세요

공격 값: <script>document.body.textContent='XSS 실행됨'</script>

공격 예시를 그대로 복사해 입력해도 됩니다. 실행은 아래 격리된 결과 화면 안에서만 일어납니다.

취약 상태: 결과 화면이 ‘XSS 실행됨’으로 바뀝니다. 방어 적용 후: script 태그 전체가 글자로 보이며 실행되지 않습니다.

03 / ACCESS CONTROL

다른 사용자의 문서 열기

문서 번호만 바꾸면 관리자 문서를 볼 수 있을까요?

정상 값: 1001 — student 소유의 내 문서

공격 값: 1002 — admin 소유의 가상 관리자 문서

취약 상태에서는 1002의 관리자 문서가 보입니다. 방어 적용 후에는 1002 접근이 거부되고 내 문서 1001은 계속 열려야 합니다.

방어 적용 후 이 페이지를 새로고침하면 위 상태 표시도 갱신됩니다. 실습 데이터는 모두 가상 데이터입니다.
